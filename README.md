# Parrilla El Mirador del Lago — Portafolio ficticio

Proyecto de portafolio (cliente **ficticio**) de Ezequiel Ingenito, desarrollador web especializado en gastronomía.

**El problema:** el restaurante, en Villa Carlos Paz (Córdoba), dependía solo de Instagram y los turistas no encontraban fácil el menú, los precios, el horario ni el teléfono. Necesitaba una web rápida, pensada para el celular, con la carta actualizable, botón de WhatsApp para reservas y ubicación en Google Maps.

**Pantallas:**
- `index.html`: Home con hero, reservas por WhatsApp, horarios y mapa.
- `menu.html`: Carta digital por categorías con precios en ARS.

Diseño generado con Google Stitch y adaptado a mano. HTML + Tailwind CSS. Publicado con GitHub Pages.

> Restaurante, teléfono y datos son ficticios.
